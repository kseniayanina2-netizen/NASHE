# Ревью и исправления

## Почему была белая страница
В коде была функция `top(...)`. В браузере `top` — встроенное свойство окна (`window.top`), его нельзя переопределить,
и весь скрипт падал с ошибкой «Identifier 'top' has already been declared» ещё до первого рендера. Функция переименована в `topBar()`.
(Синтаксическая проверка в Node этого не показывает — ошибка возникает только в браузере.)

## Исправленные ошибки
| # | Проблема | Исправление |

| 1 | Белая страница (конфликт имени `top`) | `top()` → `topBar()` |
| 2 | Тесты не открывались по клику: `JSON.stringify` внутри `onclick="…"` ломал HTML-атрибут (4 места: список тестов и варианты ответа) | добавлена `jsArg()`, которая экранирует кавычки |
| 3 | Язык по умолчанию был 中文 (интерфейс открывался на китайском) | по умолчанию «Русский» |
| 4 | `<html lang="zh-CN">` и китайский `<title>` | `lang="ru"`, заголовок по языку интерфейса |
| 5 | Плавающая строка статуса перекрывала нижнюю навигацию | убрана; пояснение про перевод — в профиле |
| 6 | В профиле было написано «контент переводится автоматически» — это неверно, машинный перевод не используется | текст приведён в соответствие |
| 7 | В легенде календаря точка «Событие» превращалась в большой круг 34 px (класс `.event` задевал `.dot.event`) | стили точек изолированы |
| 8 | В разных языках смешивались русские и английские фрагменты (например «72 тестов · 1226 questions») | слой `js/i18n-ui.js` + 46 недостающих английских строк |

| 11 | Фиксированная колонка 520 px на любых экранах | адаптивный слой `css/responsive.css` |

## Что осталось (требует вашего решения / контента)
- **Перевод контента.** Вопросы и идеи свиданий переведены только на русский и китайский. Для English/Español/… это ещё источник на русском (так и задумано в языковых пакетах, пока нет редакторского перевода). Каталог из 500 идей свиданий не переведён ни на один язык.
- **Названия тестов:** у части тестов нет английского названия («Узнай меня», «Что даёт мне ощущение близости» добавлены вручную, остальные проверьте).
