# НАШЕ — пространство для двоих

Приложение для пары: календарь, игры и вопросы друг другу, идеи свиданий, воспоминания, wish-list и «космос» (развлекательная астрология).
Чистый HTML/CSS/JS, без сборки и зависимостей. Данные хранятся в `localStorage` на устройстве.

## Запуск

Откройте `index.html` в браузере (двойной клик) — этого достаточно.
Для разработки удобнее локальный сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в корень (`index.html` должен лежать в корне).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

Все пути относительные, поэтому работает и в подпапке репозитория. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html               точка входа
manifest.webmanifest     установка на домашний экран (PWA-манифест)
css/styles.css           основные стили
css/responsive.css       адаптив: телефон / планшет / ландшафт, RTL, safe-area
js/app.js                логика и интерфейс
js/i18n-ui.js            слой перевода интерфейса (подстановка EN вместо русского)
js/data/questions.js     банк вопросов (разделы и мини-тесты)
js/data/source-options.js варианты ответов
js/data/date-ideas.js    500 идей для свиданий
js/data/language-packs.js языковые пакеты (10 языков)
js/data/photos.js        карта «ключ → файл» для фото-карточек
assets/photos/           фото для вопросов с картинками (109 шт.)
assets/icons/icon.svg    иконка
docs/REVIEW.md           что исправлено и что осталось
```

## Адаптивность

| Ширина | Раскладка |
|---|---|
| до 639 px (телефон) | одна колонка, нижняя навигация, поля ввода 16 px (без зума в iOS), учёт «чёлки» и жестовой полосы |
| 640–1023 px (планшет, портрет) | карточка 780 px, сетки в 2–3 колонки, окна по центру |
| от 1024 px (планшет, ландшафт, ноутбук) | боковая навигация слева, сетки в 2–4 колонки |

Также: поворот телефона, 320 px, арабский (RTL), `prefers-reduced-motion`.

## Языки

Интерфейс: русский, English, 中文, Español, Français, Português, Bahasa Indonesia, हिन्दी, العربية, বাংলা.
Полностью переведён контент только на русском и китайском; в остальных языках вопросы остаются на русском, пока не готов редакторский перевод.
